# spin - マウスによる図形回転サンプルプログラム

## 1. 概要

このプログラムは、マウスのドラッグ操作によって3次元空間上の物体を直感的に回転させる「仮想トラックボール」の基本アルゴリズムを学ぶためのサンプルプログラムです。以下のブログ記事の解説のために提供されています。

- [マウスで図形を回転するプログラム](https://tokoik.github.io/blog/2004/03/21/trackball.html)

マウスの2次元ドラッグ移動量をクォータニオン（四元数）による回転ベクトルに変換し、姿勢行列を更新することで、オイラー角で生じるジンバルロックを回避した滑らかな3次元回転を実現しています。

## 2. 対応環境

- Windows / macOS / Linux
- CMake 3.22 以上
- C++17 対応コンパイラ
- OpenGL 2.1 以上 (または必要なプロファイル)
- 外部ライブラリ: FreeGLUT (CMake の FetchContent により自動取得)

## 3. ビルド手順

### Windows / macOS / Linux (CMake)

```bash
cmake -B build
cmake --build build --config Release
```

## 4. 起動方法

### Windows

```powershell
.\build\Release\spin.exe
```

### macOS / Linux

```bash
./build/spin
```

## 5. 操作方法

- **マウス左ドラッグ**: 図形（トーラスや立方体等）を直感的に3次元回転させます。
- **ESC キー**: プログラムを終了します。

## 6. プログラムの解説

- **クォータニオンによる姿勢計算**:
  マウスドラッグの始点と終点の変位から回転軸と回転角を求め、増分クォータニオンを現在の姿勢クォータニオンに積算します。
- **OpenGL への適用**:
  クォータニオンから 4x4 の回転行列を生成し、`glMultMatrixd()` を用いてモデルビュー行列に掛け合わせることで、オブジェクトの姿勢に反映させています。
