# 1. 概要
このプログラムは、コンピュータグラフィックスにおける「クォータニオン（四元数）」を用いた図形の回転制御を学ぶためのサンプルプログラムです。マウスポインタをドラッグすることで、画面上の3Dオブジェクト（サインカーブを放射状に並べたような図形）を任意の方向へ滑らかに回転させることができます。回転の実装にクォータニオンを用いる理由や、計算手順の詳細は「4. 解説」を参照してください。

# 2. ビルド方法
このプログラムは CMake を用いてクロスプラットフォームでビルドできるように構成されています。各 OS 環境での手順は以下の通りです。

### Windows の場合
Visual Studio 2022 を使用してビルドします。必要なライブラリ（freeglut 等）のソースは CMake 実行時に自動でダウンロード・ビルドされます。
1. コマンドプロンプトまたは PowerShell を開き、プログラムのソースコードがあるディレクトリに移動します。
2. 以下のコマンドを実行してビルドディレクトリを作成し、CMake でソリューションファイルを生成します。
   ```sh
   mkdir build
   cd build
   cmake -G "Visual Studio 17 2022" ..
   ```
3. `build` ディレクトリ内に生成された `spin.sln` を Visual Studio 2022 で開いてください。（`spin` が自動的にスタートアッププロジェクトに設定されています）
4. Visual Studio 上で「ビルド」メニューからビルドを実行します。

### macOS の場合
Xcode を使用してビルドします。システムに最初から組み込まれている OpenGL と GLUT フレームワークを利用します。
1. ターミナルを開き、ソースコードがあるディレクトリに移動します。
2. 以下のコマンドを実行して Xcode プロジェクトを生成します。
   ```sh
   mkdir build
   cd build
   cmake -G Xcode ..
   ```
3. 生成された Xcode プロジェクト (`spin.xcodeproj`) を開きます。
4. ツールバーの左上にある Run（再生マークのボタン）を押して、ビルドと実行を行ってください。

### Ubuntu Linux の場合
`make` コマンドを使用してビルドします。事前にシステムにコンパイラや `freeglut` の開発パッケージ等が必要です。
1. 初回のみ、必要なツールとライブラリをインストールします。
   ```sh
   sudo apt update
   sudo apt install cmake build-essential freeglut3-dev pkg-config
   ```
2. ターミナルを開き、ソースコードがあるディレクトリに移動して、以下のコマンドを実行します。
   ```sh
   mkdir build
   cd build
   cmake ..
   make
   ```

# 3. 使い方

### 起動方法
* **Windows**: Visual Studio 上でデバッグ実行（F5キー）などを行うか、ビルドされた実行ファイル（例: `build\Debug\spin.exe`）を直接起動します。
* **macOS**: Xcode 上で Run を実行すると、自動生成されたアプリケーションバンドル `spin.app` が起動します。
* **Ubuntu Linux**: `make` 実行後に生成された実行ファイルをターミナルから直接起動します。
  ```sh
  ./spin
  ```

### 操作手順
1. ウィンドウが表示されると、初期状態の図形（中央にある波線の集合）が描画されています。
2. ウィンドウ内で **マウスの左ボタンを押したまま、ポインタを上下左右にドラッグ** してみてください。ドラッグした方向と量に合わせて図形が滑らかに回転します。
3. ドラッグを終了（マウスボタンを離す）すると、その姿勢を保持して図形の回転が止まります。ふたたびドラッグを行えば、現在の姿勢からさらに回転を重ね加えることができます。
4. プログラムを終了させたい場合は、キーボードの **ESC** キーを押してください。

# 4. 解説
このプログラムは、「クォータニオン（四元数）」を使用して 3D 空間での自由な回転を計算しています。

### なぜクォータニオンを使用するのか？
X軸、Y軸、Z軸それぞれの回転角度（オイラー角）を足し合わせて姿勢を管理する手法は直感的ですが、特定の角度に達すると別々の回転の軸が重なってしまい1つの自由度が失われる「ジンバルロック」と呼ばれる問題が発生します。
クォータニオンを用いると「任意のただ１つの軸周りの、任意の角度」の回転を4つの数値の組合せで扱うことができ、ジンバルロックの問題を完全に回避しながら、あらゆる方向へと破綻なく滑らかに回転する処理を計算できます。

### プログラムの処理手順とアルゴリズム
プログラム（`main.cpp`）内では、主に以下の手順でマウスの入力から回転を描画に反映させています。

1. **状態の保持（変数群）**
   *   `cq`: 現在確定している図形の「基本姿勢（回転）」を保持するクォータニオンです。初期値は `[1.0, 0.0, 0.0, 0.0]` （無回転）です。
   *   `tq`: ドラッグ中に計算される、「新しい回転」と「基本姿勢」を合成した一時的なクォータニオンです。
   *   `rt`: OpenGLに渡して実際に図形を描画するための、最終的な4x4の回転変換行列です。

2. **マウス操作からの回転量の計算 (`motion` 関数)**
   *   マウスがドラッグされると、クリック開始位置からの移動量（`dx`, `dy`）と直線距離（`a`）を計算します。
   *   この移動量から、「どの軸を中心に、どれだけの角度回転するか」という**差分クォータニオン `dq`** を生成します。X方向へのドラッグはY軸周りの回転に、Y方向へのドラッグはX軸周りの回転になるよう対応させています。
   *   作成した変更量 `dq` と、クリック時点の基本姿勢 `cq` を、クォータニオンのかけ算関数 `qmul()` で掛け合わせます。これにより、ベースとなる姿勢からの回転が合成された、新しい現在の姿勢 `tq` が得られます（`tq = dq * cq`）。

3. **OpenGL の行列への変換と描画 (`qrot`関数, `display`関数)**
   *   `qrot()` 関数では、合成されたクォータニオン `tq` を、数式によって OpenGL用の4x4の回転行列 `rt` に復元・変換しています。
   *   毎フレーム呼び出される `display()` 関数内において `glMultMatrixd(rt)` を実行し、モデルビュー行列に現在の回転を適用します。その後、ベースの波線モデル群を描画することで、画面上に回転が反映されます。

4. **回転状態の確定と保存 (`mouse` 関数)**
   *   マウスの左ボタンが離されたとき（`GLUT_UP`イベント）、操作の手が止まったととらえられます。このとき、ドラッグ計算用の現在の姿勢 `tq` をベースの姿勢変数 `cq` に保存し格納します。これが次のドラッグ開始時の新たな基準の姿勢となります。
